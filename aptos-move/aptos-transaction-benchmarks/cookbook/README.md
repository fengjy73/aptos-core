# Block-STM v2 Analysis Cookbook

本目录包含对Aptos Block-STM v2并行执行引擎的深入分析和修复文档。

## 目录结构

### principle/ - 机制原理分析
存放所有关于Block-STM v2工作机制的理论分析文档：
- 交易状态生命周期
- Stall机制原理  
- 依赖传播算法
- 并发控制策略
- 调度器设计原理

### fix/ - 代码修复文档
存放所有针对具体问题的修复方案和实现细节：
- Bug修复记录
- 性能优化方案
- 日志系统改进
- 测试验证结果

## 文档命名规范

所有文档使用以下命名格式：`YYYYMMDD-HHMM-简短描述.md`

其中：
- `YYYYMMDD`: 年月日
- `HHMM`: 24小时制的时分（大致时间）
- `简短描述`: 用连字符分隔的英文描述

例如：
- `20250822-0600-blockstm-v2-stall-mechanism-analysis.md` (上午6:00开始分析)
- `20250822-0630-stall-logging-fixes.md` (上午6:30制定修复方案)
- `20250822-0700-stall-json-field-cleanup.md` (上午7:00具体实现)

## 使用说明

1. **阅读顺序**：建议先阅读principle文件夹中的机制分析，再查看fix文件夹中的具体修复方案
2. **问题跟踪**：每个重要问题应该有对应的原理分析和修复文档
3. **版本管理**：文档按时间顺序组织，便于追踪问题解决的历程
