# Aptos Transaction Benchmarks 文档目录

本文档目录用于记录和组织Aptos交易基准测试相关的技术文档、设计方案和实现细节。

## 目录结构

### `/plans` - 规划与大纲
用于记录文档编写的规划、大纲和设计思路，包括：
- 技术方案的初步设计
- 文档编写计划
- 架构设计草图
- 问题分析框架

### `/details` - 详细文档
用于存放完整的技术文档，
## 文件命名规范

所有Markdown文件应遵循以下命名规则：
```
YYYYMMDD-HHMM-描述.md
```

示例：
- `20250822-1030-block-stm-stall-statistics-fix.md`
- `20250822-1500-performance-analysis-eth-replay.md`
- `20250823-0900-scheduler-v2-optimization-plan.md`

## 文档类型

### Plans文档
- 侧重于规划和设计思路
- 包含待办事项和实现步骤
- 便于快速了解方案概览

### Details文档

- 包含完整的技术细节
- 可作为技术参考和知识传承
- 数学变量名用$$包裹
